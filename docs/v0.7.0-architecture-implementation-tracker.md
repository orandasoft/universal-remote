## Current architecture state

The protocol-neutral command matching model is located at:

    custom_components/universal_remote/protocols/base.py

It contains:

- `CommandMatchKey`;
- `DecodedInfraredCommand`.

The compatibility facade and remaining protocol implementation are located at:

    custom_components/universal_remote/protocols/__init__.py

It still contains:

- NEC and NEC1-F16 decoding;
- NEC timing diagnostics;
- NEC repeat recognition;
- NEC normalization.

Protocol registration remains in `event.py`.

Learning maintains a separate decoder registry in `learn.py`.

The authoritative shared handler registry required by `PR-003` has not yet
been implemented.
